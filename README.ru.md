# Капсула

**От гардероба к плану путешествия — целиком в чате ИИ-агента.**

[English](README.md) · [Скачать навык](https://github.com/aydarsh/capsule/releases/latest)

Покажите фотографии вещей и назовите направление. Капсула поможет собрать образы, подтвердить требования к отелю, сравнить варианты и связать места с одеждой в маршрут по дням. Навык использует поиск и инструменты изображений вашего агента. Отдельный сервер, MCP, Docker и ключ API модели не нужны.

## Что умеет

- Ведёт короткий диалог по этапам, на вашем языке.
- Разбирает фотографии или текстовое описание гардероба.
- Собирает разные сочетания и, при наличии нужного инструмента, показывает их на едином светлом фоне.
- Предлагает связанные с одеждой требования к отелю и просит их подтвердить.
- Ищет сведения для выбранного направления, сохраняет ссылки и отмечает непроверенные условия.
- Связывает образы, места, переходы и возвращение для переодевания в план по дням.
- По просьбе оформляет заметки о поездке для сохранения и продолжения.

## Что понадобится

ИИ-агент с поддержкой навыков `SKILL.md`. Для актуальных цен, условий и мест нужен доступ к поиску; для раскладок по фотографиям — редактор изображений с поддержкой исходных снимков. Без редактора можно составить образы текстом. Голосовой ввод, подписка, стоимость инструментов и доступность вложений зависят от клиента. Навык сам не добавляет эти возможности.

## Установка через запрос агенту

В агенте с доступом к сети и локальным файлам, например Codex или Claude Code, отправьте:

> Установи навык capsule-travel из https://github.com/aydarsh/capsule. Навык находится в папке skills/capsule-travel. Установи папку целиком в каталог личных навыков этого клиента. Если навык уже установлен, сообщи об этом перед заменой.

Агент сможет скачать файлы и разместить их в нужном каталоге; при необходимости запросит разрешение. После установки откройте новый чат и вызовите `$capsule-travel` в Codex или `/capsule-travel` в Claude Code. Веб-чат без доступа к файлам и поддержки установки навыков не сможет установить его только по ссылке.

## Ручная установка

### Codex

Команды для macOS/Linux:

```sh
git clone https://github.com/aydarsh/capsule.git
cd capsule
mkdir -p "$HOME/.agents/skills"
if [ -e "$HOME/.agents/skills/capsule-travel" ] || [ -L "$HOME/.agents/skills/capsule-travel" ]; then
  echo "Навык уже установлен. Сначала сохраните предыдущую версию."
else
  cp -R skills/capsule-travel "$HOME/.agents/skills/capsule-travel"
fi
```

Откройте новый чат и вызовите `$capsule-travel`. На Windows скопируйте всю папку `capsule-travel` из `skills` в `.agents/skills` домашней папки пользователя. Вложенные папки `references` и `agents` тоже нужны.

### Claude Code

После клонирования, из папки репозитория:

```sh
claude --plugin-dir "$PWD"
```

Вызовите `/capsule:capsule-travel`. Для установки только навыка скопируйте `skills/capsule-travel` в `~/.claude/skills/`, сохранив предыдущую версию, если она есть. В новой сессии команда будет `/capsule-travel`. Выберите один способ, чтобы избежать дублирования.

### Другие клиенты

Для других клиентов есть ZIP в [релизах](https://github.com/aydarsh/capsule/releases/latest). Устанавливайте его согласно инструкции клиента, если тот поддерживает пользовательские Agent Skills. Обычный веб-чат не обязательно умеет устанавливать ZIP-навыки. Поддержка всех клиентов не заявляется.

Официальные инструкции: [Codex](https://developers.openai.com/codex/skills), [навыки Claude Code](https://code.claude.com/docs/en/skills), [плагины Claude Code](https://code.claude.com/docs/en/plugins).

## Первый запрос

Прикрепите фотографии одежды и напишите:

> Используй $capsule-travel. Хочу спланировать поездку: сначала уточни направление и даты, разбери мои вещи, затем предложи образы для прогулок и ужина. К выбору отеля перейдём после образов.

Можно начать с описания вещей, пропустить гардероб или использовать уже забронированный отель. Ограничения одним городом нет; полнота сведений зависит от доступных источников.

## Данные и ограничения

В пакете нет каталога отелей, тарифов или ответов отельеров. Цены можно назвать актуальными только после проверки предложения на нужные даты, состав гостей и тариф. Неизвестные значения остаются неизвестными. Для времени в пути нужен источник маршрута, для режима работы — сведения о месте. Выбор отеля не означает бронирование; навык не даёт агенту разрешение отправлять сообщения или платить.

Раскладки — визуализации вещей, а не гарантия точной передачи деталей или посадки. Капсула не запускает собственный сервис и не собирает телеметрию. Фотографии и запросы обрабатывает ваш клиент и подключённые инструменты по их правилам. Состояние поездки остаётся в разговоре; сохранение в файл выполняется по просьбе. Отдельной базы и автоматического переноса между чатами нет.

Для обновления сохраните установленную копию, обновите репозиторий командой `git pull --ff-only` и замените папку навыка целиком. Для удаления уберите только установленную папку `capsule-travel`. Плагин, загруженный через `--plugin-dir`, не загружается при запуске без этого параметра.

Лицензия MIT. Для проверки и сборки архива разработчиком: `python3 scripts/package.py --check` и `python3 scripts/package.py`. Python для использования самого навыка не требуется.
